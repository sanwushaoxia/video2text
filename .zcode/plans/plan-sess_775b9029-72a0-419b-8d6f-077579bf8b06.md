# 修复 torch/torchaudio CUDA 版本混装 (13.0 vs 12.8)

## 根因（已验证的事实）

`--extra-index-url https://download.pytorch.org/whl/cu128` 让 pip 在 PyPI 与 pytorch 索引间按版本号挑最高：

- **cu128 索引上 torch 最高只有 2.11.0**，PyPI 已到 2.14.0 → torch 选中 PyPI（CUDA 13.0 构建）
- **torchaudio 全网最高就是 2.11.0**（已停止发布，2.11.0 是最终版）→ cu128 索引上有 2.11.0+cu128 → torchaudio 选中 cu128（CUDA 12.8 构建）
- 结果：torch 2.14.0(CUDA 13.0) + torchaudio 2.11.0+cu128(CUDA 12.8) 混装，`import torchaudio` 时运行时检查报错

关键事实：
- 你的驱动 580.178.04 最高支持 CUDA 13.0，PyPI torch 2.14.0（自带 cu13 运行时）完全可用
- **PyPI torchaudio 2.11.0 不声明任何依赖**（无 torch pin），其 wheel 链接 `libcudart.so.13`，与 torch 2.14.0 的 cu13 体系一致
- `video2text-roformer` 环境正在用 torch 2.13.0 + PyPI torchaudio 2.11.0 正常运行（活证据）
- 修复环境只需替换 torchaudio 一个小包（几 MB），torch 2.14.0 不动

## 方案：纯 PyPI（用户已确认）

### 1. `requirements.txt`（3 处编辑）

头部：
```diff
-# PyTorch 走 cu128 (CUDA 12.8) 索引; 无 NVIDIA GPU 时见文末 CPU 说明
+# PyTorch 走 PyPI 默认源 (自带 CUDA 13 运行时); 无 NVIDIA GPU 时见文末 CPU 说明

 # --- PyTorch (CUDA 12.8 / cu128) ---
 # 运行时靠 torch.cuda.is_available() 自动选 GPU; --device cpu 可强制 CPU
---extra-index-url https://download.pytorch.org/whl/cu128
+# 注: torchaudio 已停止发布, 2.11.0 为最终版 (无 torch pin, 链接 CUDA 13);
+# 若将来 torch 换用其他 CUDA 大版本, 需重新评估 torchaudio 兼容性
 torch
 torchaudio
```
（`--- PyTorch (CUDA 12.8 / cu128) ---` 标题同步改为 `--- PyTorch (PyPI, CUDA 13) ---`）

文末 CPU 说明块（现在引用了将不存在的 `--extra-index-url` 行，需重写）：
```diff
-#   1) 临时注释掉上方 --extra-index-url 行
 #   2) pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
-#   3) pip install -r requirements.txt
-# 或保持 --extra-index-url 不变, 用显式命令强制 cu128 轮子:
-#   pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu128
+#   3) pip install -r requirements.txt   # 已装的 CPU 版会被识别, 不重复下载
```

### 2. `README.md`（2 处编辑）

- Linux 安装段：`# 已含 PyTorch (cu128) + ...` → `# 已含 PyTorch (PyPI, CUDA 13) + ...`；CPU 注释去掉"注释掉 --extra-index-url 行"字样
- Windows 安装段：`# 已含 cu128 索引的 PyTorch + 全部依赖` → 同步改写；CPU 注释同样修正

### 3. 修复 py311 环境（用户已确认）

```bash
/home/tars/miniconda3/envs/py311/bin/pip install --upgrade setuptools wheel   # 修 openai-whisper 构建缺 pkg_resources
/home/tars/miniconda3/envs/py311/bin/pip uninstall -y torchaudio              # 移除 +cu128 混装版
/home/tars/miniconda3/envs/py311/bin/pip install -r requirements.txt          # 装回 PyPI torchaudio 2.11.0 + 补齐缺失依赖
```

### 4. 修复 video2text 环境

```bash
/home/tars/miniconda3/envs/video2text/bin/pip uninstall -y torchaudio
/home/tars/miniconda3/envs/video2text/bin/pip install -r requirements.txt
```

### 5. 验证

每个修完的环境跑导入测试（CUDA 版本检查就在 import 时触发，之前就是这里报错）：
```bash
python -c "import torch, torchaudio; print(torch.__version__, torchaudio.__version__, 'cuda:', torch.cuda.is_available())"
```
预期：`2.14.0 2.11.0 cuda: True`（无 RuntimeError）。另外在 base 环境跑一次 `pip install --dry-run -r requirements.txt`（走缓存，快），确认去掉索引后解析出的 torch/torchaudio 均来自 PyPI。

## 不在本次范围

- `py312` 环境是另一种坏法（torch 2.6.0+cu124 配 torchaudio 2.11.0，版本配对本身错误），用户已选择暂不处理，总结时提醒一句。
- 不 pin torch/torchaudio 版本：bare 写法在纯 PyPI 下天然一致（torchaudio 停更在 2.11.0，torch 装最新 CUDA 13 构建），文件内注释说明约束。
